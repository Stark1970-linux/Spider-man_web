### Протокол приготовления

# Компонент А (выход ~100 г)

Инструменты: верхнеприводная мешалка, стакан 250 мл с рубашкой 40°C, сито 200 мкм, вакуумная камера, светонепроницаемый картридж, жёлтый свет.

## Шаг 1. Основа матрицы

| HTPB | 22.00 г |

| IBOA | 23.40 г |

Стакан 40°C. Смешать, 150–200 об/мин, 15 минут.

## Шаг 2. Олигомеры

| CN104 | 25.00 г |

| CN132 | 13.00 г |

Подогреть до 40°C. Влить при 200 об/мин. Перемешивать 20 минут.

## Шаг 3. Углеродное волокно

| Углеволокно 0.2–0.5 мм | 2.50 г |

800–1000 об/мин. Засыпать через сито. Перемешивать 15 минут.

## Шаг 4. Аэросил

| Aerosil 200 | 1.50 г |

Засыпать через сито при 800–1000 об/мин. Перемешивать 10 минут.

## Шаг 5. Диспергатор

| BYK-9076 | 2.00 г |

Поднять до 1500–2000 об/мин. Перемешивать 20 минут. Температура не выше 50°C.

## Шаг 6. Фотоинициаторы — жёлтый свет

| Irgacure 819 | 3.00 г |

| TPO-L | 2.00 г |

| Irgacure 784 | 1.00 г |

| BHT | 0.10 г |

Растворить в 3–5 мл IBOA (из навески шага 1). Подогреть до 50°C. Влить, перемешать 300–500 об/мин, 5 минут.

## Шаг 7. Дегазация и загрузка

Вакуум -0.9 бар, 5–10 минут. Перелить в картридж. Подать 1 бар, стравить воздух через носик. Закрыть.

# Компонент Б1 (выход ~100 г)

| Вода | 77.40 г |

| ПВС 18-88 | 12.00 г |

| Пропиленгликоль | 10.00 г |

| Борная кислота | 0.50 г |

| Бензоат натрия | 0.10 г |

1. Воду комнатной температуры. Засыпать ПВС при перемешивании. Набухать 2–3 часа.
2. Добавить пропиленгликоль, борную кислоту, бензоат натрия.
3. Перемешать до полного растворения.
4. Профильтровать 100 мкм. Залить в картридж.

# Компонент Б2 (выход ~50 г)

| Вода | 40.00 г |

| CaCl₂ | 10.00 г |

Растворить. Залить в картридж.

Порядок выстрела

1. Давление в системе: 5 бар.
2. Нажатие кнопки → три клапана одновременно.
3. Струя вылетает. Б1 + Б2 смешиваются на срезе сопла → оболочка < 0.01 сек.
4. Пьезокерамика ориентирует волокно.
5. УФ-кольцо засвечивает струю → полное отверждение 0.2 сек.
6. Нить достигает цели на дистанции 3–5 метров.
